### Accessibility Checklist

#### Folding Brochure (PDF)

- PDF name and document title clear and human readable
- PDF Metadata correct and understandable, define document language
- Set PDF links (page jumps)
- Correct flow from one panel to the next
- Color and Contrast ratio is within appropriate means
- Clear and legible font
- Images do not hold too much text, and have alt text when needed
- Run Adobe Acrobat accessibility check
- Use screen reader to test and verify

#### Markdown

- Clear filename that is human readable
- Stylized headers and sections
- Well-defined question and answer separation
- Appropriate use of font styling
- Descriptive all text for links and images
